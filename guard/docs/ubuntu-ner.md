# NER 训练交接书（Ubuntu）

> 给训练端的一切：要什么数据、什么结构、什么门槛、交回来什么。
> 板级接入见 [l2-int4.md](l2-int4.md) §3。

## 1. 模型规格（不可变）

| 项 | 要求 |
|---|---|
| 窗口 | 64 字节（板子按 32 字节重叠滑动） |
| 结构 | `emb 32 → 2 × (k3 conv 32→32) → 1×1 head`，3 类（none/name/addr） |
| 量化 | **INT8**，权重 + 每层 scale/zp + 两级 requant 乘数 |
| 尺寸 | 参数 ≤ 60k、INT8 体积 ≤ 120 KB、MAC/窗口 ≤ 4M |
| 推理 | `host/golden/ner.py` 必须是**纯 numpy 整数推理**（禁止 torch/onnxruntime） |

## 2. 数据要求

### 2.1 短句（主线）

| 项 | 要求 |
|---|---|
| 名字用字表 | ≥ 3000 个汉字（不是几十个字） |
| 全名样本 | ≥ 12 万个不同全名，三字名占多数 |
| 真人风格名 | ≥ 2000 条 |
| 地址 | ≥ 30% 带门牌号（`X号`/`X栋X单元X室`），**标注必须连续覆盖整个地址** |
| 难负样本 | `简历 学历 证书 公司 银行 流水 工资 办理 入职 投递 面试 合同 附件 扫描件 复印件 部门 岗位` 一律标 none |
| 字符对齐 | span 边界必须在 UTF-8 字符边界（生成器断言） |

### 2.2 长文档

≥ 4000 篇，每篇 300~1500 字节，文体覆盖求职信/简历/邮件/工单/合同/纪要；每篇自然含 1~4 个真 PII。

## 3. 门槛（`make ner-check`，共 16 条）

| # | 门槛 |
|---|---|
| 1–6 | 指标 / 尺寸 / 200 例向量 / numpy≡ONNX / 同 seed 复现 |
| 7 | 散文误报 ≤ 0.05 span/句 |
| 8 | 证据集 ≥ 5/7 |
| 9 | **未见过的 500+ 全名召回 ≥ 0.95** |
| 10 | 含数字地址 500+ 条整段命中 ≥ 0.98 |
| 11 | 固定名集合（马嘉祺/周杰伦/欧阳娜娜/司马相如/刘德华/杨帆/张伟）全中 |
| 12 | 长文档 200 篇：P ≥ 0.95 / R ≥ 0.90 / F1 ≥ 0.92 |
| 13 | 长文档误报 ≤ 0.05 span/100 字节 |
| 14 | 固定长信（`sim/doc_case.txt`）逐条对账 |

## 4. 交付

```bash
cd ~/QS && git checkout -b ner-v5
make test && make ner-check
git add -A && git commit -m "ner v5: human-written long-form corpus"
git push origin ner-v5
```

产物覆盖 `guard/models/ner/`（`config.json` / `vocab.json` / `weights_int8.npz` /
`quant.json` / `eval.json`），其余文件不要动（`guard/rtl/`、`docs/`）。

回报必须包含：`make ner-check` 全文、`eval.json`、仍失败的 5 条样本、push 结果
（网络不行就 `git format-patch origin/main..ner-v5`）。

## 5. 已经交回来的

| 版本 | 结果 | 板上表现 |
|---|---|---|
| v3.1 | 14 条门槛全过 | 短句正常，长信误标多 |
| **v4** | **16 条门槛全过**（长文档 P/R/F1 = 1.000、误报 0/100B） | `examples/` 五条段落 demo 逐字符正确 |

## 6. v5 要解决的（真人长文）

v4 的长文档是**生成的**，真人写的信件仍有两类误标：

| 现象 | 例子 | 板级现状 |
|---|---|---|
| 数字被误标 1 字节 | `2026年` → `*026年` | 已由 RTL 过滤（名字含 ASCII 就丢） |
| 两字词被判实体 | `再定` `近三个月` | 部分由锚点/姓氏过滤挡住 |

**v5 请求**：

1. 引入**真人写的**长文（公开新闻/公文/客服对话，脱敏后标注）≥ 2000 篇；
2. 数字/时间/金额一律 none，除非落在已标注的地址 span 内；
3. 两字词负样本加强（`再定` `每次` `本周` `园区` `周三`）；
4. 评估集加"真人长文"子集 ≥ 300 篇，门槛沿用 §3 的 12/13/14。

> 板上有兜底：姓氏表 + 地址锚点 + 标点排除。模型只要给出**大致**边界即可，细节由硬件收紧。
